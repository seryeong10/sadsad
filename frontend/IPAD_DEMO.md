# 아이패드 데모 시연

1. PC와 아이패드를 같은 개인 Wi-Fi에 연결합니다.
2. `start-ipad-demo.cmd`를 더블 클릭합니다. Flutter와 Node.js가 필요합니다.
3. 빌드가 끝나면 표시된 주소 중 실제 Wi-Fi IPv4 주소를 Safari에서 엽니다.
   PowerShell의 `ipconfig`에서 확인할 수 있습니다. `localhost`는 PC에서만 사용합니다.
4. Windows 방화벽 안내가 나오면 개인 네트워크 접근을 허용합니다.
5. PC를 절전 모드로 전환하지 말고 실행 창을 켜 둡니다. 종료는 Ctrl+C입니다.

## 3~5분 시연 순서

- 로그인 화면에서 **데모 시작하기**를 누릅니다. 계정 입력은 필요 없습니다.
- 성별 선택 → 사진 업로드 화면에서 사진 없이 다음 단계 진행.
- 퍼스널 컬러 결과 → 골격 설문 → 체형 선택 → 아바타 홈.
- 홈에서 날씨 확인 → 내 옷장에 상의·하의 등록 → 상황과 기분을 골라 내 옷 코디 추천 → 하트로 코디 저장.
- 상품 추천 화면에서는 시연용 옷 6개를 확인하고 좋아요를 누를 수 있습니다.
- 가상 피팅은 선택·결과·저장 흐름만 시연합니다. 결과는 원본 아바타입니다.
- Safari를 새로고침해도 직접 등록한 옷, 쇼핑 위시, 저장한 코디는 같은 브라우저에 유지됩니다. 시연용 옷을 자동으로 추가하지 않습니다.

## 결과의 의미

`DEMO` 표시가 있는 빌드입니다. 로그인은 인증을 생략하고, 퍼스널 컬러는 여름 쿨
고정 결과, 아바타는 선택한 기본 체형 이미지, 날씨는 고정 예시입니다.
옷 이미지는 로컬에서 그리는 시연용 일러스트이며 실제 판매 상품이 아닙니다.
내 옷 코디는 데모 조합이며 실제 AI 추론이나 얼굴 합성·옷 합성을 하지 않습니다.
백엔드 및 Firebase 없이 주요 시연 흐름을 사용할 수 있습니다.
직접 등록한 옷·쇼핑 위시·저장한 코디는 각각 분리해 기기에 저장합니다.

## 접속이 안 될 때

- PC에서 `http://localhost:8080`이 열리는지 먼저 확인합니다.
- 아이패드는 PC의 **Wi-Fi IPv4 주소**로 접속합니다. Wi-Fi가 바뀌면 주소도 바뀝니다.
- 공용 Wi-Fi는 기기 간 통신을 막을 수 있으므로 개인 공유기나 핫스팟을 이용합니다.
- 흰 화면이 나오면 Safari 탭을 닫고 새 탭에서 다시 접속합니다.
- 카메라·커뮤니티 사진 게시 대신 사진 없는 기본 흐름을 사용하세요.
- 실제 AI 전시 빌드는 데모 플래그를 빼고 서버·Firebase·HTTPS와 웹 파일 처리를 별도로 검증해야 합니다.
